# 数据库表

Folo 主要采用 SQLite，表结构定义于 `packages/internal/database/src/schemas/index.ts`，通过 Drizzle ORM 管理。

## feedsTable
- id (PK)
- title
- url (not null)
- description
- image
- errorAt
- siteUrl
- ownerUserId
- errorMessage
- subscriptionCount
- updatesPerWeek
- latestEntryPublishedAt
- tipUserIds (json)
- updatedAt (timestamp)

## subscriptionsTable
- feedId
- listId
- inboxId
- userId (not null)
- view (not null)
- isPrivate (not null, boolean)
- title
- category
- createdAt
- type (not null: feed/list/inbox)
- id (PK)

## inboxesTable
- id (PK)
- title
- secret (not null)

## listsTable
- id (PK)
- userId
- title (not null)
- feedIds (json)
- description
- view (not null)
- image
- fee
- ownerUserId
- subscriptionCount
- purchaseAmount

## unreadTable
- id (PK, subscription_id)
- count (not null)

## usersTable
- id (PK)
- email
- handle
- name
- image
- isMe (boolean)
- emailVerified (boolean)
- bio
- website
- socialLinks (json)

## entriesTable
- id (PK)
- title
- url
- content
- readabilityContent
- description
- guid (not null)
- author
- authorUrl
- authorAvatar
- insertedAt (timestamp)
- publishedAt (timestamp)
- media (json)
- categories (json)
- attachments (json)
- extra (json)
- language
- feedId
- inboxHandle
- read (boolean)
- sources (json)
- settings (json)

## collectionsTable
- feedId
- entryId (PK)
- createdAt
- view (not null)

## summariesTable
- entryId (PK)
- summary (not null)
- readabilitySummary
- createdAt (默认当前时间)
- language

## translationsTable
- entryId (PK)
- language (not null)
- title
- description
- content
- readabilityContent
- createdAt (默认当前时间)

## imagesTable
- url (PK)
- colors (json, not null)
- createdAt (timestamp, 默认当前时间)
