# 技术架构

Folo 采用现代前后端分离与多端统一架构，主要技术栈和架构如下：

## 总体架构
- **Monorepo** 管理，pnpm + TurboRepo 统一依赖与构建。
- **多端应用**：Web（SSR）、桌面端（Electron）、移动端（React Native/Expo）。
- **API 层**：Fastify + Hono + Vercel Serverless Functions。
- **数据库**：本地端采用 SQLite，服务端可扩展。
- **AI 能力**：集成第三方 AI 服务，支持摘要、翻译等。
- **内容聚合**：支持 RSS、列表、收藏、打赏等多种内容模型。

## 主要技术栈
- **前端**：React 19、Vite、TailwindCSS、React Native、Expo。
- **桌面端**：Electron + Vite。
- **后端/SSR**：Fastify、Hono、Node.js、TypeScript。
- **数据库**：Drizzle ORM + SQLite。
- **CI/CD**：Vercel、GitHub Actions。
- **工具链**：ESLint、Prettier、TSSlint、TurboRepo。

## 关键模块
- apps/desktop：桌面端主程序（Electron）。
- apps/mobile：移动端主程序（React Native/Expo）。
- apps/ssr：Web SSR 服务与 API。
- packages/internal/database：数据库 schema 与 ORM。
- api/：Serverless API（如 vercel_webhook）。
- scripts/：自动化脚本与工具。

## 配置与环境
- 多端 .env 配置，支持本地与云端部署。
- TurboRepo 任务流与依赖管理。
- Patch 机制修复依赖。

## 依赖关系
- 业务核心依赖 packages 下的共享模块（如 models、utils、hooks、store 等）。
- SSR、桌面、移动端均可调用统一的 API 层和数据库 schema。
