# 文件和函数

## 主要目录结构
- apps/
  - desktop/  桌面端主程序（Electron）
  - mobile/   移动端主程序（React Native/Expo）
  - ssr/      Web SSR 服务与 API
- api/        Serverless API（如 vercel_webhook）
- packages/
  - internal/database/  数据库 schema 与 ORM
  - configs/            配置共享
  - utils/              工具函数
- scripts/    自动化脚本
- patches/    依赖补丁
- icons/      图标资源
- locales/    多语言资源
- wiki/       文档

## 主要函数与模块关系
- apps/ssr/index.ts：Web 服务入口，注册 Fastify、API 路由、错误处理等。
- apps/ssr/src/router/global.ts：全局 SSR 路由，动态注入 meta、环境变量。
- apps/ssr/src/router/og/：OG 图生成相关路由与渲染。
- apps/ssr/src/router/static.ts：静态页面（隐私、条款）路由。
- api/vercel_webhook.ts：Vercel 部署 Webhook，自动清理 CDN 缓存。
- packages/internal/database/src/schemas/index.ts：所有表结构定义。
- apps/mobile/src/api/trending.ts：移动端热门内容 API 封装。

## 关键函数举例
- createApp（apps/ssr/index.ts）：创建 Fastify 实例，注册全局中间件和路由。
- ogRoute/globalRoute/staticRoute：注册各类 API 路由。
- injectMetaHandler（apps/ssr/src/meta-handler.ts）：动态注入 meta 信息。
- renderFeedOG/renderListOG/renderUserOG：OG 图渲染。
- 数据库相关：initializeDB、migrateDB、exportDB（packages/internal/database/src/db.*）

## 依赖与调用关系
- SSR 路由依赖 shared/env.ssr、meta-handler、lib/seo 等。
- 桌面/移动端依赖 shared、models、hooks、store、utils 等 packages 下模块。
- API 层与数据库 schema 解耦，便于多端复用。
